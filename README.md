# SkillPay AI – Student Financial Management Platform

## Overview

SkillPay AI is a student-focused financial management platform designed to help college students organize and monitor their personal finances.

The platform aims to simplify income and expense tracking, college fee management, scholarship tracking, and savings goal monitoring.

## Problem Statement

Many college students struggle to manage their finances, track expenses, remember fee deadlines, and keep track of scholarship applications.

## Proposed Solution

SkillPay AI provides a centralized platform where students can manage their financial activities and monitor their financial progress.

## Key Features

- **Student Authentication:** Individual student registration and login.
- **Dashboard:** Overview of income, expenses, and balance.
- **Income and Expense Tracking:** Record and manage transactions.
- **Student Profile:** Manage student information.
- **College Fee Management:** Monitor paid and pending fees.
- **Scholarship Tracker:** Record scholarship applications and deadlines.
- **Savings Goals:** Set financial targets and monitor progress.
- **Financial Reports:** Planned financial summaries and analysis.

## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/tharunbabi100-cmd/SkillPay-AI.git
```

2. Open the project folder:

```bash
cd SkillPay-AI
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Configure your MySQL database and environment variables locally.

5. Create the required database tables.

6. Start the Flask application:

```bash
py app.py
```

7. Open your browser:

```text
http://127.0.0.1:5000/
```
